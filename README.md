#  Custom Builder Mod - 我的世界【蓝图建造】模组

一款专为 Minecraft 1.21.4+ (Fabric) 打造的高效**蓝图建造**与结构复制模组！

## ✨ 核心特色
- 📐 **8点长方体扫描**：使用蓝图工作台激光框选，精准导出图纸与缩略图。
- 📦 **智能材料核算**：蓝图工作站自动遍历四周单箱子与大箱子库存，缺料实时提醒。
- 🛠 **自动化蓝图建造**：逐层平滑清障、流体源头精准注入、保留基岩与完美还原双格方块。
